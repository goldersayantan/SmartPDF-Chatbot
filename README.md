# 🤖 Smart PDF Chatbot

**Smart PDF Chatbot** is an intelligent web application that allows users to **upload PDF files** and **interact with the content** using natural language questions. It leverages **LLMs**, **RAG (Retrieval-Augmented Generation)**, and **Streamlit** to make document comprehension seamless and conversational.

🔗 **Live Demo:** [smartpdf-chatbot.streamlit.app](https://smartpdf-chatbot.streamlit.app/)

---

## 🧠 Features

- 📄 Upload any PDF document
- 💬 Ask questions in natural language
- ⚡ Fast and intelligent responses using LLMs
- 📚 Powered by Retrieval-Augmented Generation (RAG)
- 🧼 Clean and user-friendly Streamlit interface

---

## 🛠️ Built With

- **Python 3**
- **Streamlit** – UI Framework
- **Langchain / Gemini API** – LLM integration
- **PyMuPDF / pdfplumber** – PDF parsing
- **FAISS / Chroma** – Vector store for semantic search
- **OpenAI / Gemini / LlamaIndex** – Language Model (depending on your setup)

--

## 🧪 Example Use Cases
- Understand research papers by querying them
- Ask questions from textbooks or study material
- Explore product manuals and legal documents
- Customer support with PDF-based knowledge base
